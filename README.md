# chatbox-app

> **Historical project**
>
> This application is historical, unmaintained, and not intended for deployment. Client configuration is embedded into frontend builds and is not confidential.
>
> Repository changes do not verify or secure the old backend. Provider-side database, storage, authentication, API restrictions, and authorized domains have not been reviewed. External service status and current compatibility have not been verified.

ReactJS. Résultat du deuxième projet du tutoriel ReactJS pour débutants. Application permettant de chatter avec d'autres utilisateurs en utilisant une base des données commun (firebase). 

Attention pour le contenu des messages : il n'y a aucun contrôle en place pour prévenir les utilisateurs mal intentionnés.

## Historical usage (unverified)

The following inherited instructions are retained for historical context and have not been validated.

`npm install`

`npm start`
